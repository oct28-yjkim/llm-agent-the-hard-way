# Lab 07 — Memory

## 목표

대화 상태와 장기 메모리를 구분하고, 저장할 정보와 저장하지 않을 정보를 정책으로 결정합니다.

## 구현

- working memory, episodic memory, user preference를 분리합니다.
- 쓰기 전 민감정보 필터와 사용자 승인 규칙을 적용합니다.
- TTL, 수정, 삭제, provenance 필드를 추가합니다.
- memory retrieval이 답변에 미친 영향을 기록합니다.

## 실패 주입

잘못된 기억, 오래된 선호, 다른 사용자의 정보, 삭제된 정보를 주입합니다.

## Done Check

- 저장 이유와 출처를 추적할 수 있습니다.
- 사용자별 데이터가 섞이지 않습니다.
- 기억이 없는 상태에서도 안전하게 동작합니다.
