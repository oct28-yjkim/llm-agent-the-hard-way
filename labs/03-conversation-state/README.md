# Lab 03 — Conversation State

## 목표

다중 턴 대화를 저장하고 제한된 컨텍스트 예산 안에서 필요한 정보만 유지합니다.

## 구현

- 메시지, 사용자 입력, 도구 결과를 서로 다른 타입으로 저장합니다.
- 전체 히스토리, 요약, 서버 관리 continuation을 비교합니다.
- 오래된 대화를 요약하되 중요한 제약은 보존합니다.
- 턴별 입력 토큰과 상태 크기를 기록합니다.

## 실패 주입

긴 대화, 상충하는 지시, 잘못된 요약, 도구 결과 누락을 재현합니다.

## Done Check

- 상태 저장 위치와 보존 기간을 설명할 수 있습니다.
- 요약 전후에 핵심 제약이 유지됨을 테스트합니다.
- 삭제 요청 시 관련 상태를 찾을 수 있습니다.
