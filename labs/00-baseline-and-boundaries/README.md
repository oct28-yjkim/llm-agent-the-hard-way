# Lab 00 — Baseline and Boundaries

## 목표

에이전트가 해결할 한 가지 업무를 정하고 성공, 실패, 위험한 행동의 경계를 먼저 정의합니다.

## 구현

- 대표 입력 10개와 어려운 입력 5개를 작성합니다.
- 품질, 비용, 지연시간의 기준선을 정의합니다.
- 읽기 작업과 side-effect 작업을 구분합니다.
- 승인 없이 절대 실행하면 안 되는 행동을 목록화합니다.

## 실패 주입

모순된 지시, 빠진 정보, prompt injection 문구가 포함된 문서를 입력합니다.

## Done Check

- 좋은 결과와 나쁜 결과를 제3자가 판정할 수 있습니다.
- 에이전트가 하지 말아야 할 행동이 명시되어 있습니다.
- 이후 Lab에서 사용할 고정 테스트 세트가 준비되었습니다.
