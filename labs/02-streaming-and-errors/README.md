# Lab 02 — Streaming and Errors

## 목표

SSE 스트림을 직접 읽고 부분 출력, 중단, 재연결을 다룹니다.

## 구현

- 이벤트 단위 parser를 작성합니다.
- 부분 텍스트와 최종 완료 상태를 분리합니다.
- connect/read timeout을 각각 설정합니다.
- retry 가능한 오류와 즉시 실패할 오류를 분류합니다.

## 실패 주입

중간 연결 종료, 중복 이벤트, 순서가 잘못된 이벤트, 429 응답을 재현합니다.

## Done Check

- 화면 출력과 내부 상태가 중복되지 않습니다.
- 재시도가 같은 side effect를 두 번 실행하지 않습니다.
- 취소 요청 후 스트림과 작업이 모두 종료됩니다.
