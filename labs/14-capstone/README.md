# Lab 14 — Capstone Research Agent

## 목표

지금까지 만든 부품을 결합해 근거 기반 리서치 에이전트를 완성합니다.

## 필수 기능

- 질문을 작업 계획으로 분해합니다.
- 로컬 문서와 허용된 최신 출처를 검색합니다.
- 주장마다 출처를 연결하고 근거가 없으면 보류합니다.
- 파일 저장이나 외부 전송 전 승인을 요청합니다.
- 중단·재개와 실패 복구를 지원합니다.
- 대표 데이터셋에서 품질, 비용, latency를 보고합니다.

## 최종 산출물

- 실행 가능한 애플리케이션
- 아키텍처와 신뢰 경계 문서
- 최소 25개 사례의 eval 데이터셋
- 실패 사례와 개선 이력
- 단일 에이전트/멀티 에이전트/SDK 버전 비교표
